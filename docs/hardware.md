# 硬件连接

## 1. 最小系统

CH552 需要：

* `VCC`：5 V（USB VBUS）或 3.3 V
* `GND`
* USB `D+` = P3.7，`D-` = P3.6
* `V33`：芯片内部 3.3 V LDO 输出，按官方参考电路接电容
* `UCAP`/`VDD` 等按数据手册接去耦电容

USB 差分线尽量等长、靠近接口，D+/D- 各串 22 Ω 左右电阻（很多成品
CH552 小板已经集成）。

## 2. 默认矩阵

```
            列0       列1       列2       列3
            P3.0      P3.1      P3.2      P3.3
             |         |         |         |
行0 P1.0 --- K00 ----- K01 ----- K02 ----- K03
             |         |         |         |
行1 P1.1 --- K10 ----- K11 ----- K12 ----- K13
             |         |         |         |
行2 P1.2 --- K20 ----- K21 ----- K22 ----- K23
```

* 行：推挽输出，固件逐行拉低。
* 列：准双向输入，打开内部上拉。
* 按键按下时把对应列拉低。

### 二极管

建议每个键串一只 1N4148 / 1N5819：

```
列 ──|>|── 行
     阳极  阴极
```

也就是电流从列流向被拉低的行。没有二极管时，同时按三个键可能形成
“鬼键”路径，导致多出一个按键。

## 3. 4 键直连板（But1–But4 + WS2812 灯链）

对应 `firmware/include/board_4key.h`：

```
But1 ── P1.7 ── GND
But2 ── P1.6 ── GND
But3 ── P1.4 ── GND
But4 ── P3.2 ── GND

P1.5 ── 330Ω ── WS2812 DIN ── 后续灯珠 DIN ...
外部 5V ─────── WS2812 VCC
GND ─────────── WS2812 GND
```

按键是低电平有效，内部上拉打开。P1.5 使用 GPIO 软件 bit-bang，不再使用
SPI0，因此 P1.7 可以安全地接 But1。默认键位为 `1 2 3 MO(1)`，按住
But4 时前三键变成 `F1 F2 F3`。默认按 4 颗 WS2812（每键一颗）配置；
只有 1 颗也能工作，多余的数据会从第一颗的 DOUT 移出。

4 键板使用标准 8 字节 boot keyboard（无 report ID、无 Consumer 集合），
这是 Windows 10/11 下已验证可用的形式；因此 4 键板不发送多媒体键。

编译：

```bash
make BOARD=4key
```

注意：bit-bang 时序按 12/16 MHz 校准，24 MHz 会编译报错。

## 4. 直连模式

每个按键独立：

```
P1.0 ── 按键 ── GND
P1.1 ── 按键 ── GND
...
```

配置：

```c
#define KEYBOARD_MODE       KEYBOARD_MODE_DIRECT
#define DIRECT_KEY_COUNT    6
#define DIRECT_PINS { {1,0}, {1,1}, {1,2}, {1,3}, {3,0}, {3,1} }
```

直连模式不需要行线，也不会有矩阵鬼键问题（每个键独立读取）。

## 5. WS2812

```
CH552 P1.5 ── 330Ω ── WS2812 DIN
CH552 GND  ────────── GND
外部 5V    ────────── VCC
```

* P1.5 是 SPI0 MOSI；P1.7 是 SPI0 SCK，保留但不接 LED。
* 数据方向是单向的，不需要 MISO。
* 每颗灯并联 100 nF 去耦电容；整条灯带入口加 100–470 µF 电解电容。
* 12 颗全白约 700 mA，USB 500 mA 端口带不动，建议外部 5 V 供电。
* 固件默认亮度 64/255；可以在 VIA 里调低。
* 3.3 V 供电时，WS2812 的 DIN 高电平可能接近其最小值，建议使用
  3.3 V 兼容灯珠或加电平转换。

## 6. 引脚分配建议

默认占用：

| 用途 | 引脚 |
|------|------|
| 矩阵行 0–2 | P1.0–P1.2 |
| 矩阵列 0–3 | P3.0–P3.3 |
| WS2812 | P1.5、P1.7（SCK 保留） |
| USB | P3.6、P3.7 |

可用：

* P1.3、P1.4、P1.6
* P3.4、P3.5

注意：

* P3.2 同时是 INT0 / VBUS1，用作普通 GPIO 没问题，但不要接 USB VBUS 检测。
* P3.0/P3.1 是 UART0，本固件不使用调试串口。
* P1.5 同时是 SPI0 MOSI 和 PWM1 备选，启用 RGB 时归 RGB 使用。

## 7. 烧录

CH552 出厂带有 WCH USB ISP bootloader：

1. 按住板上的 BOOT/下载键（若有）再插入 USB；没有按键时，先上电再让
   WCHISPTool 重新连接；
2. 电脑出现 `4348:55E0`；
3. 用 WCHISPTool 烧 `build/ch552_qmk.hex`；
4. 重新上电，默认 3×4 固件应枚举为 `1209:5523`；4 键固件为
   `1209:5524`。

如果固件里配置了 `QK_BOOTLOADER`，按一下该键即可跳回 bootloader。
